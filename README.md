## 1. 为什么要给 Shopify 独立站单独配一条IEPL 专线

先说 Shopify 本身。Shopify 的官方说明写过,它对访问的IP 类型没有硬性要求,不论固定IP、动态IP或代理IP,只要出口IP 与店铺注册地区大体一致、不在常见风险名单上,通常不会直接报错。所以"单纯访问 Shopify 后台"并不是非要 IEPL 不可。

真正需要稳定 IEPL/IPLC 出口的场景集中在三处:

- **广告投放环境**:TikTok Ads、Meta BM、Google Ads 对账号登录 IP、网络抖动、IP 风险分敏感。专线能避免家庭宽带和普通 VPN 常见的 IP 跳变、晚高峰拥堵、DNS 污染。
- **支付与收款链路**:Stripe、Shopify Payments、Adyen、pingpong、连连等虽然走自己的服务器,但在后台人工复核时,会参考发起请求的网络指纹,跨地区反复跳转会被标记。
- **多账号/多店铺运营**:两个独立站共用同一出口 IP 很容易被平台判定关联。在 IEPL 环境下,可以给每个店铺分配独立的入口 IP 和出口IP,做硬隔离。

MKCloud 的官网把它自己定位成「合规跨境电商专线服务器」,主营IEPL、IPLC、IX 三类专线 VPS,核心卖点是端内延迟低（广港端内1~3ms）、IP干净(Scamalytics 风控分数 0)、双端独立 IP（一个入口、一个出口）。这些技术指标对独立站卖家的实际意义是:"从国内操作一台 VPS,VPS 的出口 IP 是固定、干净、可按省份要求选择的白名单 IP"——比直接用家里宽带或公共 VPN 都更可控。

## 2. IEPL、IPLC、IX 三种线路到底怎么选

这三个名词在跨境圈被混用得很厉害,先在这里拆清楚。

- **IEPL(国际以太网专线)**:基于 MSTP 平台、以太网接口的点对点专线。MKCloud 产品里的「广港IEPL」就属于这一类,出口固定,延迟极低。
- **IPLC(国际私有租赁线路)**:基于 SDH/PDH 的传统专线,稳定性顶级,延迟比 IEPL 略高,但带宽可选范围更细。
- **IX(上云互联优化专线 / IXP)**:实际上不是物理专线,而是经过优化路由、连接云厂商网络出口的「准专线」。延迟表现不错,价格最低,但稳定性比真正的 IEPL/IPLC 稍差。

对 Shopify 独立站用户来说,差距大致是:

- 香港为主要收款、广告、Shopee/Lazada 业务 → 选**广港IEPL**,延迟最低、入口多(八线动态 BGP/电信/移动/联通三选)。
- 主要做日本市场、TikTok 日区、亚马逊日本站 → 选**沪日IPLC**,入口UCloud BGP/电信,端内25~28ms。
- 主要做欧美市场、Stripe 收款、Facebook 美区广告 → 选**沪美IPLC**,端内124~134ms。
- 预算紧张、对极致延迟不敏感,只想要「比家里宽带稳」 → 选**深港/沪日/沪港/沪美 IXP**,¥158/月起步。
- 做跨境收款、对安静度要求极高 → 选**沪港IPLC 独享带宽**、**泉港/厦港高防IPLC**。

按这个分类去选套餐,基本不会绕远路。

## 5. 购买前的几个实操问题

**Q1:必须实名认证吗?**

是的。MKCloud 的服务条款明确写了:

- 个人用户:提供手机号、姓名、身份证号(依据《网络安全法》第二十四条实名要求);
- 企业用户:提供企业名称、营业执照编号、法人身份证号、对公银行账户。

IEPL/IPLC 系产品必须实名,IXP 上云互联系列在限制上略宽松。

**Q2:只支持支付宝?**

目前是。MKCloud FAQ 写明「只支持支付宝进行付款,更多支付方式敬请期待」。如果有 USDT 或 PayPal 需求,得用第三方代充渠道,代充本身是灰色方案,这里不展开。

**Q3:开通要多长时间?**

VPS 系产品在付款完成后约 1 分钟左右自动开通。如果是独立物理服务器或定制配置,需要走工单流程,通常 12~24 小时交付。

**Q4:退款规则?**

MKCloud 在 FAQ 里写明「仅支持质量问题退款」,服务开通后不支持更换其他地域。如果对质量有疑问,需要提供具体延迟数据、速度数据作为凭证。这一点和其他普通 VPS 不一样——你下单前最好确认自己的业务地区和入口省份是匹配的。

**Q5:一个 VPS 可以绑多个 IP 吗?**

不可以。每台 VPS 默认分配 1 个独立入口 IP 和 1 个独立出口 IP,直连产品绑定一个省份,可在控制台切换,但同一台机器不允许多 IP 共存——这就是MKCloud 在多账号隔离上给出的解决方案:一台机器 = 一个独立 IP 环境,多账号就开多台机器。

**Q6:Sharpe带宽和独享带宽怎么算钱?**

MKCloud 知识库明确:共享带宽是峰值,不保证持续跑满;独享同样不保证24小时任意目标满速,但抖动和被他人影响的可能性小得多。预算紧张时共享 + 1TB 起步够用;广告矩阵、收款链路需要更稳的环境时,建议直接独享。

**Q:IEPL 比普通的香港CN2 GIA 强在哪里?**
